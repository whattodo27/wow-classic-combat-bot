# MKOAgent Combat v1

Рабочая копия репозитория `MatthewOglesby/MKOAgent` для локального прототипа боёвки в радиусе.

## Что уже есть

- Поиск окна игры по подстроке заголовка.
- Захват только найденного окна.
- Подключение к Ollama через `127.0.0.1:11434` без системного HTTP-прокси.
- Короткий JSON-ответ без поля `reasoning`; обрезанный JSON не исправляется догадками.
- Детерминированный конечный автомат: поиск цели → проверка → сближение → бой → лечение/питомец/отступление.
- Allowlist целей с запретом игроков, элитных, редких и неизвестных имён.
- Настраиваемые клавиши и слоты `1–9`.
- По умолчанию включён `dry-run`: бот печатает запланированное действие, но не нажимает клавиши.

Навигация, карта, лут, город и полный фарм-цикл намеренно не реализованы.

## Текущая ротация

Профиль `combat_config.json` разрешает только `Young Nightsaber` и задаёт:

1. периодически нажимать `Tab` для перебора nearby-целей;
2. для первой подтверждённой цели нажать слот `1` дважды с интервалом `2.0 с`;
3. если цель ещё далеко, удерживать `W` для сближения;
4. когда цель в ближнем бою, нажать слот `2`;
5. повторять слот `2` через случайный интервал `1.0–1.3 с`;
6. если цель стала запрещённой, исчезла или умерла, вернуться к поиску следующей цели.

Все значения находятся в `combat_rules` файла `combat_config.json`.

## Запуск

Из этой папки в Git Bash:

```bash
.venv/Scripts/python.exe -m unittest discover -s tests -v
.venv/Scripts/python.exe main.py
```

По умолчанию профиль настроен на окно `World of Warcraft` и `dry-run`.

## Включение реального ввода

Сначала проверь, что в журнале появляются строки примерно такого вида:

```text
SEARCHING  target=None exists=False ... action=DRY-RUN press 'tab' [no_target]
FIGHTING   target='Young Nightsaber' exists=True ... action=DRY-RUN press '1' [opening_attack]
FIGHTING   target='Young Nightsaber' exists=True ... action=DRY-RUN press '2' [melee_attack]
```

Если модель продолжает возвращать `target=None` или неверное имя, не включай реальный ввод: это проблема распознавания, а не ротации.

Для переключения на реальные клавиши установи в `combat_config.json`:

```json
"live_input": true
```

Перед этим убедись, что окно игры активно, а слоты `1` и `2` действительно назначены нужным способностям.

## Проверка

```bash
.venv/Scripts/python.exe -m unittest discover -s tests -v
```

В рабочей копии есть диагностические скрипты `diagnose_capture.py`, `capture_only.py` и `one_shot_test.py`. Одноразовый тест не должен нажимать атаку, если имя цели не подтверждено как `Young Nightsaber`.

В исходной папке репозитория сохранён оригинальный код. Эта папка — отдельная рабочая копия.
